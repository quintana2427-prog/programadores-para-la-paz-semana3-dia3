Responde con tus propias palabras.

1. ¿Qué significa repetir instrucciones en programación?

Respuesta: Es hacer que un mismo código se ejecute varias veces sin escribirlo muchas veces.

2. ¿Qué es un ciclo while?

Respuesta: Es un ciclo que repite algo mientras se cumpla una condición.

3. ¿Qué significa la condición dentro de un while?

Respuesta: Es la regla que indica si el ciclo sigue o se detiene.

4. ¿Por qué es importante cambiar una variable dentro del while?

Respuesta: Porque si no cambia, el ciclo nunca se va a detener.

5. ¿Qué es un ciclo infinito?

Respuesta: Es un ciclo que nunca se detiene porque la condición siempre se cumple.

6. ¿Qué hace el comando npm run practicar?

Respuesta: Ejecuta un script llamado “practicar” que está configurado en el proyecto.

7. ¿Dónde está definido el comando practicar?

Respuesta: Está definido en el archivo package.json, en la parte de “scripts”.

8. ¿Qué diferencia hay entre node archivo.js y npm run practicar?

Respuesta: node archivo.js ejecuta directamente un archivo, mientras que npm run practicar ejecuta un script definido que puede correr uno o varios comandos.

9. ¿Cómo puede servir un while para revisar varias fuentes de información?

Respuesta: Permite repetir el proceso de revisión varias veces, pasando por cada fuente hasta terminar todas.

10. ¿Cómo puede relacionarse un ciclo con el seguimiento de propuestas comunitarias?

Respuesta: Se puede usar para revisar continuamente el estado de las propuestas, actualizarlas y dar seguimiento de manera ordenada.
